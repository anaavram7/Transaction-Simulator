# Heistbank

**Heistbank** este un simulator bancar digital modern și modular, conceput pentru gestionarea sigură a conturilor și a tranzacțiilor financiare. Aplicația oferă o interfață grafică intuitivă și un sistem robust de autentificare și stocare a datelor.

## 🛠️ Tehnologii utilizate
Proiectul folosește următoarele tehnologii principale:
* **Python** – limbajul de bază pentru logica de business, servicii și controlere.
* **SQLite** – baza de date locală cu auto-inițializare și criptare securizată a parolelor.
* **CustomTkinter** – biblioteca modernă pentru crearea interfeței vizuale.
